# SOAR Studio

**Comprehensive Engineering Analysis Platform for Rocket Design**

SOAR Studio is a web-based engineering platform for designing rockets, simulating flights, analyzing trajectories, and visualizing propulsion physics in real time. It supports water rockets, solid rocket motors, and custom thrust profiles with advanced analysis capabilities including Monte Carlo uncertainty quantification, parameter sweeps, and design of experiments.

## Features

### Simulation & Physics
- **Water Rocket Propulsion** — Isothermal expansion model with accurate thrust, mass flow, and pressure dynamics
- **Solid Motor Propulsion** — Commercial Estes motors (A8 through F15) with built-in thrust curves
- **Custom Thrust Curves** — CSV import for user-defined thrust profiles
- **RK4 / RK45 Solvers** — Advanced numerical integration replacing Euler as the default
- **ISA Standard Atmosphere** — Altitude-dependent density, temperature, and pressure model
- **Wind Model** — Constant, layered, and altitude-varying wind profiles
- **Advanced Aerodynamics** — Mach-dependent drag, multiple nose cone types, fin drag

### Analysis & Visualization
- **Parameter Sweeps** — Vary one parameter across multiple simulations with automatic comparison plots
- **Monte Carlo Analysis** — Run hundreds of simulations with random perturbations to quantify uncertainty
- **Design of Experiments** — Full factorial experiments testing every parameter combination
- **Engineering Dashboard** — Dynamic pressure, Mach number, energy, and impulse visualization
- **Real-time Trajectory Visualization** — Interactive charts powered by Recharts

### Rocket Designer
- **Visual Rocket Builder** — Real-time 2D SVG rendering that updates instantly as you edit engineering parameters
- **Parametric Design** — Grouped parameter cards for geometry, mass, aerodynamics, propulsion, and launch
- **Drag-Based Editing** — Click-and-drag handles to resize rocket components directly on the canvas
- **Design Presets** — Start from Beginner, Competition, or Experimental rocket configurations
- **Local Storage** — Designs persist across sessions with save/reset
- **Inline Validation** — Impossible values (negative lengths, water > bottle) are rejected with clear error messages
- **Single Source of Truth** — The rocket model drives both the visualization and all derived calculations

### Engineering Properties (v2.3)
- **Live Engineering Panel** — Automatically recalculated properties synced with every design change
- **Geometry Properties** — Overall length, body length, nose length, maximum diameter, cross-sectional area, aspect ratio, frontal area
- **Mass Breakdown** — Dry mass, water mass, total launch mass with stacked visual distribution bar
- **Propulsion Metrics** — Water volume, fill percentage, initial pressure, nozzle diameter and area
- **Aerodynamic Properties** — Drag coefficient, launch angle, frontal area
- **Metric / Imperial Units** — Toggle between SI and imperial display at any time
- **Engineering Warnings** — Rule-based warnings for out-of-range parameters (pressure, water fill, aspect ratio, fin count, nozzle size)
- **Engineering Summary** — Deterministic engineering observations generated by rule-based logic
- **Copy & Export** — Copy properties to clipboard or export as JSON for external use

### Stability Analysis (v2.4)
- **Center of Gravity (CG)** — Weighted component-mass estimation from nose tip (accounts for nose, body, bottle, water, fins, nozzle, recovery)
- **Center of Pressure (CP)** — Simplified Barrowman approximation using normal force coefficients from nose, body, and fins
- **Stability Margin** — (CP - CG) / body diameter in calibers with automated rating (Excellent → Unstable)
- **Visual Indicators** — Blue CG and red CP markers overlaid on the rocket SVG with dashed separator line
- **Stability Marker Bar** — Interactive bar showing CG and CP positions as percentages of rocket length
- **Stability Recommendations** — Deterministic, rule-based engineering recommendations (no AI) for improving stability
- **Stability Explainer** — Collapsible educational section explaining CG, CP, calibers, and why stability matters
- **Live Updates** — CG, CP, and stability margin recalculate instantly on every geometry or mass change
- **Export** — Stability data included in both text and JSON engineering exports

### Mission Analysis (v2.5)

### Backend Architecture

The backend is organized into modular domains:

- **`/app/api/routes.py`** — REST API endpoints (`POST /api/simulate`)
- **`/app/physics/`** — Physics engine:
  - `engine.py` — Core physics (drag, gravity, equations of motion)
  - `solvers.py` — Euler, RK4, and RK45 numerical integrators
  - `atmosphere.py` — ISA standard atmosphere model
  - `aerodynamics.py` — Mach-dependent drag, nose cone types, fin drag
  - `wind.py` — Constant, layered, and altitude-varying wind profiles
  - `propulsion/` — Water rocket, solid motors (Estes), custom thrust curves
- **`/app/analysis/`** — Analysis engine (sweeps, Monte Carlo, DoE, statistics)
- **`/app/schemas/`** — Pydantic models with camelCase API serialization
- **`/app/validation/`** — Flight data comparison and validation framework
- **`/app/workspace/`** — Project management, rocket library, reports

### Frontend Architecture

The frontend is organized by route and component:

- **`/src/app/`** — Next.js pages (landing, simulate, validate, analyze, workspace, designer)
- **`/src/components/`** — React components:
  - `ui/` — shadcn/ui primitives (tabs, cards, sliders, buttons, etc.)
  - `simulation-form.tsx` — Rocket configuration form
  - `flight-charts.tsx` — Trajectory visualization with 4 chart tabs
  - `sweep-panel.tsx` — Parameter sweep UI
  - `monte-carlo-panel.tsx` — Monte Carlo analysis UI
  - `doe-panel.tsx` — Design of Experiments UI
  - `rocket-designer/` — Visual rocket builder with SVG renderer, parameter panel, engineering properties
- **`/src/lib/`** — API clients, utilities, engineering module, geometry types, presets
- **`/src/lib/engineering/`** — Engineering module (v2.3):
  - `geometry.ts` — Pure geometry calculations
  - `mass.ts` — Mass and weight calculations
  - `properties.ts` — Combined engineering properties
  - `warnings.ts` — Rule-based engineering warnings
  - `summary.ts` — Deterministic engineering observations
  - `units.ts` — Metric/Imperial unit conversion

### Engineering Properties (v2.3)

Every geometric change immediately updates engineering properties:

| Category | Properties |
|----------|-----------|
| **Stability (v2.4)** | CG from Nose, CG from Tail, CG Position %, CP from Nose, CP from Tail, CP Position %, Stability Margin (calibers), Rating (Excellent/Good/Marginal/Poor/Unstable), CG-CP Separation |
| **Geometry** | Overall Length, Body Length, Nose Length, Maximum Diameter, Cross-Sectional Area, Estimated Internal Volume, Aspect Ratio (L/D), Frontal Area |
| **Mass** | Dry Mass, Water Mass, Total Launch Mass, Water Fill %, Mass Distribution (stacked bar) |

| **Aerodynamics** | Drag Coefficient (Cd), Launch Angle, Frontal Area |
| **General** | Design Version, Last Modified, Component Count |

### Calculation Assumptions

- All internal calculations use SI (metric) units
- Water density: 1000 kg/m³ (fresh water at standard conditions)
- Internal volume: cylindrical approximation using body tube inner diameter and bottle volume
- Nozzle area: circular cross-section at throat
- Mass distribution: component masses as specified in the design model
- Aspect ratio: total length / maximum body diameter
- Warnings are rule-based, deterministic — no AI is used
- Engineering summary observations are generated from deterministic rules

### Stability Calculation Assumptions (v2.4)

**CG Methodology:**
- Components modelled as point masses at their geometric centers
- Nose cone CG: depends on shape type (conical=66%, ogive=47%, parabolic=50%, elliptical=53% from tip)
- Body tube CG: at geometric center
- Bottle CG: at geometric center of bottle section
- Water CG: same as bottle CG (water occupies bottle volume)
- Fins CG: at fin position + 30% of root chord from leading edge
- Nozzle CG: at geometric center of nozzle

**CP Methodology (Simplified Barrowman):**
- Normal force coefficients computed for nose cone, body tube, and fins
- Nose cone: CN = 2 × (baseRadius/bodyRadius)², adjusted for shape type
- Body tube: small constant contribution (CN = 0.02) — negligible at subsonic speeds
- Fins: CN = body-fin interference factor × fin count × (span/diameter)²
- Overall CP = Σ(CNᵢ × xᵢ) / Σ(CNᵢ)

**Limitations:**
- Valid for subsonic flow (Mach < 0.3) and small angles of attack
- Simplified fin model using trapezoidal approximation
- Body-fin interference effects are not modelled in detail
- Does not account for angle-of-attack effects on CP shift
- Not valid for transonic or supersonic flight regimes
- Approximation only — real CP should be verified with flight testing

**Architecture:**
The CP module (`cp.ts`) is designed for future replacement with more advanced methods (panel methods, CFD-informed corrections, or empirical correlations) without affecting the UI or other calculations.

## Physics Model

### Water Rocket

The water rocket uses compressed air to expel water through a nozzle:

1. **Isothermal Expansion**: `P = P₀ × V_air₀ / V_air(t)`
2. **Exit Velocity**: `v_exit = √(2 × (P - P_atm) / ρ_water)`
3. **Thrust**: `F = 2 × A_nozzle × (P - P_atm)`
4. **Mass Flow**: `ṁ = ρ × A_nozzle × v_exit`

### Assumptions

- Isothermal expansion (no temperature drop)
- Incompressible water
- Quasi-steady flow
- Perfect nozzle efficiency
- Optimal expansion (exit pressure = atmospheric)

### Validated Behaviors

| Test | Result |
|------|--------|
| Higher pressure → higher altitude | ✅ |
| More water → longer burn | ✅ |
| Mass decreases during burn | ✅ |
| Pressure drops to atmospheric | ✅ |
| Water exhausts to zero | ✅ |
| Negative pressure rejected | ✅ |
| Water > bottle rejected | ✅ |
